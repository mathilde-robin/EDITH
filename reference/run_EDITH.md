# Main function to run EDITH analysis.

Main function to run EDITH analysis.

## Usage

``` r
run_EDITH(palette = "classic")
```

## Arguments

- palette:

  Character string specifying the color palette for synergistic data.
  Options are "classic" (green-black-red) or "alternative"
  (blue-black-orange).

## Value

pdf and excel files saved in the output directory.
