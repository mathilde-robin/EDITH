# Checks on the input data matrix.

Checks on the input data matrix.

## Usage

``` r
checks(data_init, drug_names, type)
```

## Arguments

- data_init:

  A matrix or array containing the initial data.

- drug_names:

  A character vector containing the names of the drugs.

- type:

  An integer indicating the type of experiment: 2 for two-drug
  combinations, 3 for three-drug combinations.

## Value

A cleaned numeric matrix if all checks are passed; otherwise, NULL.
