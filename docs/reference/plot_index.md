# Plot the calculated indexes (AI, CI, EI) for each drug concentration.

Plot the calculated indexes (AI, CI, EI) for each drug concentration.

## Usage

``` r
plot_index(index_df)
```

## Arguments

- index_df:

  A data frame containing the calculated indexes: Additivity Index (AI),
  Combination Index (CI), and Efficacy Index (EI) for each drug
  concentration.

## Value

A patchwork plot with three bar plots for AI, CI, and EI.
